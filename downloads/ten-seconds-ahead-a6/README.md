# Ten Seconds Ahead — A6 Amber Noir

30-second portrait video, 1080×1920, 24fps, H.264/AAC stereo.

The approved free local route retains the navy hoodie, changes the face to matte black with cream marks, uses amber/plum illustrated lighting, a white upper-left title, and outlined uppercase captions with amber active-word highlights. Added effects are tied to the story: prediction pulses, glints, wet footsteps, motion spray, headlight atmosphere, rescue accents and a stereo bus pass.

The rig uses fixed-length IK chains, connected joints and planted stance feet. All 720 frames passed the numerical rig checks; source values are in joint-diagnostics.json. Decoded-frame checks and numerical geometry do not replace complete human audiovisual review. Exact scope and remaining limitations are in QA.json.

Open the MP4 in a video player or use preview.html. Include the music credit in CREDITS.md in the description if publishing. The SRT carries plain text/timing; the highlighted styling is burned into the MP4.

No paid APIs used. No existing Video Shotcraft or installed skill files changed. This is local 2D animation, not a Flow/Veo or Renoise generation; narration reuses the approved local voice rather than claiming Gemini Puck. Original project sources, timing and provenance remain in the parent project folder.
