# Demo A5 — Thiên kiến xác nhận
30-second Vietnamese psychology animation. 1080×1920 portrait, 24 fps.

Fictional Roman marketplace: a shopper favors a beautiful apple as confirmation of his belief, dismisses a bruised apple, then considers both. This illustrates a general cognitive tendency, not a diagnosis or a claim about an actual historical event.

Original locally rendered 2D character animation, original synthesized plucked-string music and effects. Vietnamese narration runs locally using sherpa-onnx and the Piper vi_VN-vais1000-medium model; no paid APIs. Voice is synthetic. See model card and provenance for source and attribution. VAIS1000 dataset: https://ieee-dataport.org/documents/vais-1000-vietnamese-speech-synthesis-corpus — CC BY 4.0 https://creativecommons.org/licenses/by/4.0/ . Narration is generated output, not an original corpus recording.

Only this demo is produced; continuation awaits user feedback. Existing repository files and installed skill are unchanged.
