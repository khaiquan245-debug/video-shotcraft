# Ten Seconds — reference character and voice edition

1920×1080, 30 fps illustrated English film. The default export plays at 1.1× speed (10% faster), lasts 7min16s, and preserves voice pitch. The original eight-minute composition remains available with `npm run render:base`. The character is redrawn from the user-supplied reference: white face, spiky black hair, navy hoodie, outlined limbs and sneakers. Speech is synthesized with local ZipVoice conditioned on an extract from the supplied video. Exact speaker identity or indistinguishability is not claimed.

## Render and edit

```sh
npm ci
npm run studio
npm run render
```

Linux Chromium is configured at `/usr/bin/chromium`. Change the browser path for another installation. Generated audio is frozen as lossless FLAC, so rendering requires no speech model, private reference, API key, or voice service.

`src/Art.tsx` defines the character. `src/Scenes.tsx` defines animated scenes. `src/timeline.json` is the shared source of captions, timing, and action cues. `src/workbench.ts` enables Motion Workbench editing. The complete 12-scene Ten Seconds screenplay is retained; the reference video's reflexes storyline is not substituted.

Outputs: `out/ten-seconds-1.1x.mp4`, its music-free companion, English SRT and editable source archive. See `REFERENCE-ADAPTATION.md` for visual and voice decisions.

## Optional speech regeneration

Requires Python, `sherpa-onnx==1.12.26`, numpy, ffmpeg, the official ZipVoice Distill INT8 zh-en model and Vocos24kHz. Supply the original/private reference extract and its accurate transcript using `VOICE_REFERENCE_WAV` and `VOICE_REFERENCE_TEXT_FILE`. Set `ZIPVOICE_MODEL_DIR` and `ZIPVOICE_VOCODER` to downloaded model paths. Reference media and model weights are intentionally excluded from the project.

Run `tools/narrate.py`, `tools/mix.py`, `tools/separate-clock.py`, `tools/sync-events.py`, `tools/split-captions.py`, and `tools/balance-captions.py`, then convert the four final WAV tracks to FLAC. Regeneration changes audio and timings; rerender and review the whole film afterward.

## Provenance and review

Screenplay supplied by the user. Character design adapted from their uploaded reference; scene illustrations/animation and procedural underscore created for this project. Voice generated by reference-conditioned synthesis, not a recording of a new performance by the reference speaker. Full narration underwent automated ASR coverage checks; speaker embedding similarity is supporting evidence only and is not a listening assessment. See `qa/` for the saved validation reports.
