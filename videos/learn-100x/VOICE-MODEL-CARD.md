# PocketTTS FP32 voice

Engine: sherpa-onnx1.13.8. Model: sherpa-onnx-pocket-tts-2026-01-26 (full FP32), five flow steps, native speed1.0. Speaker conditioning uses the same private eight-second user reference. PocketTTS does not require a reference transcript. No previous production voice clips or ZipVoice outputs are mixed into this edition.

Model files and private references are not distributed in this project. Frozen generated audio is provided for repeatable rendering.

The generated voice aims to resemble the supplied sample. Exact speaker identity is not claimed. The user explicitly selected the newly generated opening voice sample; ASR/speaker-embedding measurements are supporting checks, not a listening assessment of the complete film.
